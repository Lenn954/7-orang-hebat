# Stickers

Folder ini berisi asset stiker yang digunakan di Photo Editor.

## Format yang didukung
- `.svg` (recommended — scalable)
- `.png` (dengan transparent background)
- `.webp`

## Cara menambahkan stiker baru
1. Tambahkan file gambar ke folder ini
2. Update `index.js` di folder ini untuk mendaftarkan stiker baru
3. Stiker akan otomatis muncul di palette editor

## Naming convention
- Gunakan lowercase dengan dash: `heart-red.svg`, `star-gold.png`
- Prefix dengan kategori: `love-heart.svg`, `nature-flower.svg`, `deco-ribbon.svg`
